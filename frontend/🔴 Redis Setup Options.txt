🟡 AWS Credentials Needed for S3
To enable AWS S3 image storage, you need:

Credential	Description	Where to Get
AWS_ACCESS_KEY_ID	Your AWS access key	IAM Console → Users → Security Credentials
AWS_SECRET_ACCESS_KEY	Your AWS secret key	Same as above (shown only once when created)
AWS_REGION	Region for your bucket	e.g., us-east-1, eu-west-1
S3_BUCKET_NAME	Your S3 bucket name	S3 Console → Create Bucket
