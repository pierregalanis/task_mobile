<product_requirements>
The primary objective is to build a mobile app version, named Soutrali, of an existing TaskRabbit clone web app called AfricaTask. The mobile app is to be built using React Native/Expo.

**Core Features:**
-   **Full Feature Parity:** The mobile app must replicate all features of the web app, including authentication (for Client and Tasker roles), service browsing by categories, Google Maps integration for location services, a complete booking flow, user dashboards, in-app chat, reviews/ratings, a favorites system, and payment integration with Paydunya.
-   **Phased MVP Development:**
    -   **Phase 1 (Complete):** Authentication (Login, Signup), and basic tab navigation.
    -   **Phase 2 (In Progress):** Browse Taskers (list, filters, profiles), Service Selection, and a basic booking form.
    -   **Future Phases:** Google Maps, Task Management, Chat, Notifications, etc.
-   **Design:** Default dark mode with an emerald green (#10b981) theme, matching the web app's aesthetic.
-   **Localization:** The app must be fully bilingual (English and French) from the start, with a user-facing toggle. All 13 primary service categories and their 40 subcategories must be translated.

**Technical Pivot:**
While initially specified to connect to a pre-existing backend API, its unreliability forced a pivot. A local FastAPI/MongoDB backend was created to support mobile app development and is the currently active backend.
</product_requirements>
